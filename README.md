# AD&D 1e 角色卡 Character Sheet

一个可直接在浏览器里打开的 AD&D 1e 角色卡：空白卡起步、手动掷骰建卡、按 1e 规则自动查表与提示。单文件、无后端，数据只存在你自己的浏览器 localStorage 里。

在线用（GitHub Pages）：https://lukeTheNeuromancer.github.io/adnd-1e-character-sheet/
本地用：直接用浏览器打开 `index.html` 即可，不用联网、不用装任何东西。

## 功能

- **空白卡起步**：打开即空白卡，不预填任何人物。
- **分步建卡向导**：掷属性 → 选种族职业 → 卓越力量 → HP → 起始金币 → 语言 → 武器 → 法术书 → 身份 → 汇总。
  - 全程手动掷实体骰、逐颗填骰面，超范围标红拦截；不提供数字自动掷骰建卡。
  - 属性方法：3d6 顺序 / DMG 方法一（4d6 去最低，自由分配）/ DMG 方法三（3d6 两次取高）。
  - 向导只开新卡，不覆盖现存角色。
- **规则推导与检测**：主属性经验加值、力量命中/伤害与最大负重、敏捷防御与远程调整、体质 HP 调整、智力学会率与每级法术数、感知奖励法术、魅力随从与反应、THAC0、豁免、每日法术位。
- **非熟练惩罚按职业自动**：战士 -2 / 牧师·盗贼 -3 / 法师 -5。
- **钱币、装备与负重**：10 枚硬币 = 1 磅，1 磅 = 10 gp；超重会提醒。注意：买装备不会自动扣钱，请手动在钱币栏扣除。
- **法术书**：法师开局含 Read Magic；学会检定掷百分骰 ≤ 学会率即学会；已记忆数超过每日法术位会提醒。
- **多角色管理**：新建、保存、删除、导出/导入 JSON；另有通用骰盘与掷骰记录。

## 规则出处

数值表按 AD&D 1e《玩家手册》（PHB）与《城主指南》（DMG）整理。如与你的书本版本有出入，以书本与 DM 裁定为准，欢迎提 issue 修正。
